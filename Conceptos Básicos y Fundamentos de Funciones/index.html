Aplanar arreglos

Aplana arrays anidados a un único array usando flat(Infinity).

  • Cómo combinar varios arrays en uno (concat / spread).
  • Uso de flat(Infinity) para aplanar cualquier profundidad anidada.
  • Ventaja: facilita el procesamiento posterior (map, filter, reduce). 
let arraysanidados = [
  "hola",
  "Buenos dias",
  ["Hello World", 1, 2, 3, 4],
  ["A", "B", "C", ["Puuto", "El que lo lea"]],
];
let arrayDos = ["Mamaweboi", 1, 2, 4, 5, 66, 77, 88, 99];
let arraynueve = [
  "hola",
  "Buenos dias",
  ["Hello World", 1, 2, 3, 4],
  ["A", "B", "C", ["Puuto", "El que lo lea"]],
];

const aplanarArray = (...arrays) => {
  // 1. Unimos todos los arrays de entrada en una sola lista (el Array Maestro)
  const arrayMaestro = [].concat(...arrays);

  // 2. Usamos flat(Infinity) para aplanar cualquier nivel de profundidad
  return arrayMaestro.flat(Infinity);
};
console.log(aplanarArray(arraysanidados, arrayDos, arraynueve));

Calculadora

Función calcular que soporta sumar, restar, multiplicar y dividir con manejo de división por cero.

  • Normalizar entradas (por ejemplo operacion.toLowerCase()) para robustez.
  • Uso de switch para elegir la operación y mantener el código claro.
  • Manejo de errores (e.g., división por cero) y retorno de mensajes útiles. 
const calcular = (operacion, num1, num2) => {
  switch (operacion.toLowerCase()) {
    case "sumar":
      return num1 + num2;

    case "restar":
      return num1 - num2;

    case "multiplicar":
      return num1 * num2;

    case "dividir":
      if (num2 === 0) {
        return "Error: No se puede dividir por 0";
      }
      return num1 / num2;

    default:
      return " operacion invalida";
  }
};

let resultado = calcular("Dividir", 3, 0);

console.log(resultado);

Contador de caracteres

Cuenta la frecuencia de cada carácter en una cadena, ignorando espacios y normalizando a minúsculas.

  • Iterar sobre una cadena y usar un objeto como contador (mapa simple).
  • Normalizar caracteres (toLowerCase()) para contar sin distinguir mayúsculas/minúsculas.
  • Ignorar caracteres no deseados (espacios) y usar short-circuit para inicializar contadores. 
let cadenas = new String("Hola que hace");

const contadorCaracteres = (cadena) => {
  let objetoAuxiliar = {};

  for (let caracter of cadenas) {
    if (caracter == " ") {
      continue;
    }

    caracterminuscula = caracter.toLowerCase();
    objetoAuxiliar[caracterminuscula] =
      (objetoAuxiliar[caracterminuscula] || 0) + 1;
  }

  return objetoAuxiliar;
};

console.log(contadorCaracteres(cadenas));

Eliminar números repetidos

Filtra y devuelve sólo los números que aparecen una vez en el array.

  • Contar ocurrencias con reduce para construir un mapa de frecuencias.
  • Filtrar por valores cuyo conteo sea 1 para obtener elementos únicos.
  • Patrón útil para eliminar duplicados manteniendo sólo elementos no repetidos. 
let numeros = [1, 1, 4, 5, 6, 7, 8, 9, 9, 10, 3, 5, 11, 88, 100];

const numerosLimpios = numeros.reduce((contador, num) => {
  contador[num] = (contador[num] || 0) + 1;
  return contador;
}, {});

const filtrarNumeros = numeros.filter((num) => {
  const conteo = numerosLimpios[num];
  return conteo === 1;
});

console.log(filtrarNumeros);

Filtrar pares

Devuelve todos los números pares usando filter.

  • Uso de filter para extraer elementos que cumplen una condición.
  • Operador módulo (%) para verificar paridad.
  • Función pura y fácil de componer con otras transformaciones (map, reduce). 
numeros = [2, 5, 7, 9, 11, 13, 16, 100, 11111, 1231456, 123144, 234, 2345];
const esPar = numeros.filter((num) => num % 2 === 0);

Gestión de inventario

Estructura simple de inventario con funciones para agregar y comprar productos con control de stock.

  • Uso de objetos como mapas para almacenar stock por clave.
  • Funciones que modifican estado y validaciones (producto inexistente, stock insuficiente).
  • Patrones básicos de mutación y retorno de mensajes para feedback al usuario. 
inventario = {
  jabon: 50,
  shampoo: 30,
  arroz: 100,
  pasta: 75,
  aceite: 40,
  detergente: 60,
};

function agregarProducto(producto, cantidad) {
  if (inventario[producto] == undefined) {
    inventario[producto] = cantidad;
  } else {
    inventario[producto] += cantidad;
  }
}

agregarProducto("papaya", 20);

console.log(inventario);

agregarProducto("jabon", 20);

console.log(inventario["jabon"]);

compraProducto = (producto, cantidad) => {
  if (inventario[producto] == undefined) {
    agregarProducto(producto, cantidad);
    return (
      "El producto no existe en el inventario pero vamos a agregarlo agregarlo\n",
      inventario
    );
  } else if (inventario[producto] < cantidad) {
    return "No hay suficiente inventario del producto";
  } else {
    inventario[producto] -= cantidad;
    return `Compra exitosa. Quedan ${inventario[producto]} unidades de ${producto}`;
  }
};

let producto = "Guayaba";
let cantidad = "5";

let mensaje = compraProducto(producto, parseInt(cantidad));

console.log(mensaje);

Suma y promedio

Suma elementos de un array y calcula su promedio con manejo para arrays vacíos.

  • Uso de reduce para acumular valores eficientemente.
  • Control para casos borde (array vacío) y uso de operador ternario.
  • Atención a la precisión y validaciones antes de operar con números. 
let numeros = [];
const sumaArreglos = numeros.reduce((acc, numero) => {
  return acc + numero;

const promedio = numeros.length > 0 ? sumaArreglos / numeros.length : "PLUTO";

Verificador de palíndromos

Verifica si una cadena o número es palíndromo; ignora espacios y mayúsculas.

  • Normalizar la entrada (eliminar espacios y bajar a minúsculas) antes de comparar.
  • Invertir cadenas (split('').reverse().join('')) para comparación simple.
  • Aplicable a palabras, números y frases tras el preprocesado. 
const esPalindromo = (palabra) => {
  let palabraLimpia = palabra.replace(/\s/g, ""); // Elimina espacios en blanco
  let palabraRevertida = palabraLimpia.split("").reverse().join(""); // Lo convierte en un arrai se revierte y el join hace que se retorne una nueva cadena

  return palabraLimpia.toLowerCase() === palabraRevertida.toLowerCase();
};
