Proyectos de practica web

Veremos distintos proyectos donde estare retando mi logica al ver y usar HTML, CSS y JavaScript, algunos solo tendran html y css pero el proposito de esto es mostrar mi practica y asu ves mostrar todo lo quue he aprendido colocando temas aprendidos en cada uno de ellos retos y demas

  • Conceptos logica

    Este proyecto trata de conceptos basicos de logica y fundamentos de funciones en JavaScript.

  • Contador

    Este proyecto trata de un contador simple con botones de incremento, decremento y reinicio.

  • Conversor

    Este proyecto trata de un conversor de unidades de medida.

  • Formulario HTML

    Este proyecto trata de un formulario HTML con validaciones.

  • Snake

    Este proyecto trata de un juego de snake con controles

  • Cronometro

    Este proyecto trata de un cronometro con funciones de pausa y reinicio.

  • Pomodoro

    Este proyecto trata de un temporizador Pomodoro con funciones de pausa y reinicio.

  • Cifrado cesar

    Este proyecto trata de un cifrado cesar con funciones de encriptacion y desencriptacion

  • Clone Wordle

    Este proyecto trata de un juego similar a Wordle con funciones de adivinanza de palabras.
